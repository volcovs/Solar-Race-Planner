# Instructions for AI coding assistants

Read [README.md](README.md), [docs/data-contracts.md](docs/data-contracts.md) and
[docs/architecture.md](docs/architecture.md) first.

- Work on one ticket at a time.
- Run the lint and test commands in [README.md](README.md) before proposing a change.
- Never write secrets, keys or data files into the repo.
- Never commit or push; leave that to the person.
- Keep the project generic: no team or car names in code, docs or UI.
